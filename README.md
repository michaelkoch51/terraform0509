## Задание 1: Исправление ошибок и запуск конфигурации

1. **Инициализация проекта:**  
   Проведена успешная инициализация проекта с помощью команды `terraform init`. Ограничение версии в `providers.tf` было скорректировано с `~>1.12.0` на `>= 1.12.0` для обеспечения совместимости с установленной версией Terraform `1.14.8` на macOS darwin_arm64.

2. **Суть исправленных синтаксических и логических ошибок в `main.tf`:**
   * В блоке `resource "yandex_compute_instance"` конфигурация ресурсов процессора и памяти была ошибочно обернута в блок `resource { ... }` вместо множественного числа **`resources { ... }`**.
   * Параметр гарантированной доли CPU был задан как `core_fraction = 1`. Так как Yandex Cloud для базовых платформ поддерживает только значения **5, 20 или 100**, значение было изменено на минимально допустимое — **5**.
   * Идентификатор платформы содержал опечатку — `standart-v4` вместо **`standard-v1`** (через «d»). Кроме того, конфигурация `cores = 1` не поддерживается данной платформой, минимальное количество ядер изменено на **2**.
   * Была допущена ошибка интерполяции при получении ID образа операционной системы: `data.yandex_compute_image.ubuntu.image_id`. Исправлено на валидный атрибут **`.id`**.

3. **Использование параметров `preemptible = true` и `core_fraction=5`:**
   * **`preemptible = true` (Прерывистая ВМ):** Снижает стоимость аренды виртуальной машины в облаке на 60–70%. Машина может быть остановлена Яндексом в любой момент или автоматически удалена через 24 часа. Это идеальный выбор для учебы, тестирования и экономии личного учебного гранта.
   * **`core_fraction = 5` (Базовая доля CPU):** Гарантирует виртуалке только 5% мощности физического процессора. Для легковесных тестов и разворачивания базовых конфигураций Terraform этого более чем достаточно, при этом стоимость ресурсов падает в разы.

4. **Проверка подключения по SSH:**
   Виртуальная машина успешно создана. Ключ `id_ed25519` успешно импортирован через метаданные. Авторизация и проверка внешнего IP-адреса внутри ВМ:
   ```bash
   ssh -i ~/.ssh/id_ed25519 ubuntu@93.77.191.134
   ubuntu@fhmn0978hbsqehgqidv5:~\$ curl ifconfig.me
   93.77.191.134
   ```
